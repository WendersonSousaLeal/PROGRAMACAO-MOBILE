## Como executar
Os projetos foram desenvolvidos no [Expo Snack](https://snack.expo.dev/). Existem duas formas de executá-los:

**Opção 1 — Direto pelo Expo Snack (mais simples)**
1. Acesse o link do Snack da atividade desejada (adicione o link na tabela de Conteúdo acima, ex.: `https://snack.expo.dev/@seu-usuario/nome-do-snack`).
2. Escaneie o QR Code exibido na página com o app **Expo Go** no celular, ou use o simulador web/mobile embutido no próprio site.

**Opção 2 — Rodando localmente**
1. Clone o repositório:
   ```
   git clone https://github.com/WendersonSousaLeal/PROGRAMACAO-MOBILE.git
   ```
2. Acesse a pasta da atividade:
   ```
   cd "Atividade Portfólio/Meu_Portfolio-main"
   ```
3. Instale as dependências:
   ```
   npm install
   ```
4. Inicie o projeto com o Expo:
   ```
   npx expo start
   ```
5. Escaneie o QR Code com o app **Expo Go** (Android/iOS) ou abra em um emulador.

## Requisitos
- Node.js (apenas para rodar localmente)
- App **Expo Go** instalado no celular (Android/iOS)
